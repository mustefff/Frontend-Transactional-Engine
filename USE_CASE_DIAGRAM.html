Système de Paiement Mobile - Équipe 4

👥 Acteurs du Système

👤 Client

Description : Utilisateur final de l'application mobile

Rôle :

  • S'inscrire et se connecter
  • Effectuer des paiements
  • Consulter son solde
  • Acheter des produits

🏪 Marchand

Description : Commerçant qui accepte les paiements

Rôle :

  • Générer des QR Codes
  • Recevoir des paiements
  • Consulter ses transactions
  • Gérer son compte marchand

🛒 Vendeur E-commerce

Description : Vendeur sur la plateforme e-commerce

Rôle :

  • Gérer les produits
  • Traiter les commandes
  • Gérer les stocks
  • Expédier les produits

👨‍💼 Administrateur

Description : Gestionnaire du système

Rôle :

  • Gérer les utilisateurs
  • Superviser les transactions
  • Gérer les litiges
  • Configurer le système

📧 Système de Notification

Description : Service externe (Équipe 3)

Rôle :

  • Envoyer des SMS
  • Envoyer des emails
  • Envoyer des OTP

📋 Légende des Relations

Association (→) Relation directe entre un acteur et un cas d'utilisation.
Exemple : Client → S'inscrire
Inclusion (-.-> inclut) Un cas d'utilisation en inclut obligatoirement un autre.
Exemple : Passer commande inclut Payer commande
Extension (-.-> étend) Un cas d'utilisation peut en étendre un autre (optionnel).
Exemple : Ajouter au panier étend Parcourir catalogue
Dépendance (-.->) Interaction avec un système externe ou un autre service.
Exemple : Inscription -.-> Système de Notification
